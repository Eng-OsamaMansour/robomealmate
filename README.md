# 🤖 RoboMealMate

> AI-Powered Humanoid Waiter Robot for Restaurant Service

RoboMealMate is a humanoid-inspired AI-powered robot designed to autonomously assist in restaurant environments. It combines **robotics**, **AI**, **natural language processing**, and **SLAM-based navigation** to provide smart, human-like customer service.

---

## 🎯 Project Goals

- Deliver food and interact with customers
- Navigate autonomously using SLAM and obstacle avoidance
- Understand and respond to voice commands
- Display expressions and communicate visually
- Integrate with restaurant systems for real-time updates

---

## 🧠 Key Features

- 🧭 **Autonomous Navigation** using ROS 2 + RPLIDAR + Ultrasonic sensors  
- 🎙️ **Voice Recognition** with Google Cloud Speech-to-Text  
- 🗣️ **Conversational AI** using OpenAI GPT models  
- 🖼️ **Facial Emotion Display** via LCD screen  
- 🧠 **Object Detection & Image Processing** (OpenCV-based)  
- 📋 **Order taking via touchscreen** with intuitive GUI  
- 🔊 **Speaker + Microphone Array** for clear interaction

---

## ⚙️ Hardware Components

- 🤖 **Chassis:** Custom humanoid frame with mecanum wheels  
- 🧠 **Controller:** Raspberry Pi 4 (64-bit OS) + Arduino Mega 2560  
- 📡 **Sensors:** 
  - RPLIDAR A1M8 (LiDAR for SLAM)  
  - Multiple HC-SR04 ultrasonic sensors  
  - MPU-6050 IMU for balance  
- 🎥 **Camera Module:** For image processing  
- 📺 **7-inch Touch LCD** (GUI + face expressions)  
- 🔊 **Amplified Speaker + Mic Array**

---

## 🧰 Software Stack

- **Programming Languages:** Python, C++ (Arduino), Bash  
- **OS & Frameworks:** Ubuntu + ROS 2 Humble  
- **SLAM & Navigation:** Nav2, RPLIDAR, TF  
- **AI & NLP:** OpenAI GPT, Google STT, LangChain  
- **Vision:** OpenCV  
- **GUI:** PyQt / Tkinter (for touchscreen interaction)  
- **Communication:** Serial + ROS topics/services
